`# 🚢 DockShip

DockShip is a production-ready Docker infrastructure for Node.js APIs.

## Supported Deployments
- ✅ Host Nginx (recommended)
- ✅ Nginx in Docker

## Why DockShip?
Because most Docker tutorials stop before production.

DockShip shows how to run Node + Prisma + Postgres + Redis:
- Securely
- Behind Cloudflare
- With proper isolation

## Recommendation
Use **Host Nginx** for real VPS deployments.
Use **Docker Nginx** for portability.
